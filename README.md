# SFS1112 Physics for Life Sciences: Light and Optics

Asynchronous lecture for SFS1112 (A261), Bachelor of Food Biotechnology, FST, USIM.

**Students, start here:** https://arifjamali-90.github.io/sfs1112-optics/

- Ten short narrated videos and a closing clip (about 28 minutes), each followed by a checkpoint question.
- Pause-and-try prompts inside the videos, and four try-at-home activities.
- An exit ticket and a completion slip to screenshot and submit as instructed.
- The lecture slides: `SFS1112_Lecture_10_Optics_I_and_II.pptx`.

Use the same device and browser for the whole lecture; progress is saved in your browser only.

Script and slides by Dr. Muhamad Arif Mohamad Jamali. Narration uses a synthetic voice; the presenter is an illustrated character.
